# Монитор-Отладчик для ПК-6128ц
Данная программа сделана на базе ПО ["Монитор-Отладчик" для ПК "Вектор-06ц"](https://caglrc.cc/scalar/ware/696/), команды и возможности программы можно посмотреть в [документации](https://caglrc.cc/scalar/ware/774/).

## Дополнительные директивы
<b>B</b> -- Загрузка данных с магнитной ленты в формате ROM. Директива "BM" выполняет загрузку со смещением на 1 блок.<br>
<b>G</b> -- Директива G получила дополнительный ключ "-G" -- запуск программ с переключением экрана на Банк 1 (08000h..0FFFFh).<br>
<b>J</b> -- Очистка экрана, аналогична последовательности команд "K"+"ВК"; "СТР"; "F4".<br>
<b>Y</b> -- Определение константы чтения программ с магнитной ленты.<br>
<b>Z</b> -- Показать экран по стандартным адресам Вектора (Банк 1, 08000h..0FFFFh), возсрат по нажатию любой клавиши.

## Распределение памяти
Для программ пользователя выделены все 64кБ нижней памяти ПК-6128ц (Банк 0 и 1), кроме ссылок по адресам 00000h..00002h, 00005h..00007h, 00028h..0002Ah, 00038h..0003Ah, а также области векторов вызова Монитора-Отладчика, 0FE00h..0FFFFh (вариант загрузки №1 -- максимум памяти) или 07E00h..07FFFh (вариант №2 -- без вмешательства в область экрана ПК "Вектор-06ц").<br>
Сам Монитор-Отладчик работает по адресам 14000h..17FFFh (Банк 2), экран используется по адресам 18000h..1FFFFh (Банк 3).
